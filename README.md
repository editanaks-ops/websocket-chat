# 💬 WebSocket Chat

Простой чат в реальном времени на WebSocket.

##  Возможности
- Подключение пользователей
- Отправка сообщений в реальном времени
- Отображение "кто онлайн"
- Уведомления о входе/выходе
- Разделение сообщений (свои / чужие)

##  Технологии
- Python (websockets)
- HTML / CSS / JavaScript
- WebSocket

##  Запуск

### 1. Сервер
```bash
python serve/main.py
```

### 2. Клиент

Открыть: http://127.0.0.1:8000/index.html
